这个简明教程对Ubuntu 14.04历史文件清理进行了说明，它用于初学者。


要从dash搜索删除历史记录，请遵循以下程序。


转到系统设置（System Settings）并打开安全与隐私（Security & Privacy）。


![](https://linuxcn.static.byte.beer/data/attachment/album/201410/15/221755dq0rhzg2hgvrqu15.png)


在文件与应用（Files and Applications）标签下，点击清除用户数据（Clear Usage Data）。


![](https://linuxcn.static.byte.beer/data/attachment/album/201410/15/221756hpps2iuk45rq5555.png)


你也可以关闭“记录文件与应用使用（Record file and Application usage）以阻止系统记录你当前使用的文件和应用。


![](https://linuxcn.static.byte.beer/data/attachment/album/201410/15/221800rtqqpv4ws3j5jv44.png)
